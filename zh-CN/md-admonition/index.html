可折叠提示框

将 collapsible="+" 设置为默认展开，collapsible="-" 设置为默认折叠。

代码：

:::warning{title="点击展开" collapsible="-"}
仅在展开后才会显示的隐藏细节。
:::

:::info{title="默认展开" collapsible="+"}
本节默认展开。点击摘要可折叠。
:::

结果：

⚠️点击展开▼

仅在展开后才会显示的隐藏细节。

💡默认展开▼

本节默认展开。点击摘要可折叠。

指令标签标题语法

除了 title="..."，还可以将第一个子节点写成 [label] 来设置标题：

代码：

:::warning[v3 中的重大变更]
默认导出已被移除，请改用命名导出。
:::

结果：

⚠️v3 中的重大变更

默认导出已被移除，请改用命名导出。

❌常见陷阱

避免这些错误：

  1. 硬编码路径

    // ❌ 不好
const path = 'C:\\Users\\neo\\file.txt';
// ✅ 好
const path = require('path').join(__dirname, 'file.txt');

  2. 缺少错误处理

    • 总是使用 try-catch 块
    • 验证用户输入
    • 正确记录错误

  3. 忽略 async/await

    回调函数会导致”回调地狱”。使用现代异步模式。
